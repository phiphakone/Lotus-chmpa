# Lotus & Champa — ฉบับปรับปรุงเว็บไซต์

วันที่ตรวจ: 7 ตุลาคม 2026

เว็บไซต์ต้นทาง: https://phiphakone.github.io/quiz/#/

## สิ่งที่ปรับแล้ว

- ปรับสีหลักเป็นเขียวเข้ม งาช้าง และทองเข้ม เพิ่มความชัดของข้อความ
- ลดขนาดหัวเรื่องหน้าแรก จัดระยะห่างและลำดับเนื้อหาให้กระชับ
- ปรับหน้าแรก รายการสินค้า รายละเอียดสินค้า ตะกร้า ขั้นตอนสั่งซื้อ บล็อก ติดต่อ เกี่ยวกับบริษัท โมเดลธุรกิจ และหน้าบัญชีให้ใช้รูปแบบเดียวกัน
- รองรับหน้าจอ 375px, 768px และ 1440px
- แสดงตัวกรองแบบเปิด/ปิดบนมือถือ และแก้ตัวกรอง OCOP กับตัวกรองป้ายสินค้าที่ใช้ตัวพิมพ์ต่างกัน
- แก้ปุ่มเพิ่มจำนวนที่ถูกยอดราคาทับในตะกร้าบนมือถือ
- เพิ่มชื่อช่องกรอก ลิงก์ข้ามไปเนื้อหา กรอบโฟกัส เมนูและหน้าต่างภาพที่ใช้คีย์บอร์ดได้
- แยกปุ่มรายการโปรดออกจากลิงก์สินค้า แก้ลิงก์บทความให้เป็นลิงก์จริง
- เพิ่มปุ่มหยุด/เล่นภาพเลื่อน และรองรับการลดการเคลื่อนไหวตามการตั้งค่าผู้ใช้
- แยกรูปฝัง 25 ภาพเป็นไฟล์ โดยตรวจ SHA-256 ว่าภาพไม่เปลี่ยน

## ข้อมูลที่รักษาไว้

ข้อมูลเริ่มต้นของสินค้า 41 รายการ บล็อก คำแปลทั้งห้าภาษา การเชื่อมต่อ Firebase คีย์ข้อมูลในเบราว์เซอร์ และเวอร์ชันข้อมูลเดิมไม่เปลี่ยน ตรวจเปรียบเทียบเนื้อหาส่วนเหล่านี้กับต้นฉบับแล้ว ไฟล์ต้นฉบับอีก 61 ไฟล์รวมถึง firestore.rules และ storage.rules ยังคงเหมือนเดิมทุกไบต์ ไม่ได้ลบหรือแก้ข้อมูลคำสั่งซื้อ ผู้ใช้ หรือฐานข้อมูลจริง

## เปิดดูบนเครื่อง

1. ดับเบิลคลิก `Start-Preview.cmd` บนเครื่องที่มี Node.js
2. เปิด http://127.0.0.1:4173/#/ ในเบราว์เซอร์
3. เมื่อตรวจเสร็จ ปิดหน้าต่างที่รันตัวอย่าง

เว็บไซต์เป็นไฟล์แบบ static ไม่ต้อง build เมื่อต้องการเผยแพร่ ให้ใช้ `index.html`, โฟลเดอร์ `assets`, `images`, และ `.nojekyll` ของฉบับนี้ โดยรักษาเส้นทางโฟลเดอร์ไว้ รูปที่แยกออกจาก HTML จำเป็นต้องอัปโหลดไปด้วย

ยังไม่ได้เผยแพร่ฉบับนี้ขึ้น GitHub Pages การส่งมอบครั้งนี้เป็นโครงการในเครื่องตามคำขอ
